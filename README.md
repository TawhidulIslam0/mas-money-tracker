# MMAS: Money Tracker

> An optimized application for daily expense tracking and finance management. <br />

## Setup

Run the following commands from your terminal:

1) Clone this repository into a directory outside OneDrive (for example, `C:\src\mmas-money-tracker-main`).
2) Run `flutter pub get` in the project root directory to install all the required dependencies.
3) Start the Android emulator, then run `flutter run -d emulator-5554`.

On Windows, building from a OneDrive-synced directory can prevent Flutter from deleting generated build files. If that happens, move or clone the repository outside OneDrive before running Flutter commands. If Android reports insufficient internal storage during installation, free space in the emulator and run the command again.
